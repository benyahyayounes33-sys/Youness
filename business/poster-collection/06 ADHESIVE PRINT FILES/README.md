# Adhesive versions

**Use the same PDFs** (folders 03 / 04 / 05). Self-adhesive paper or vinyl prints the same artwork. No separate file is needed as long as the shop hasn't asked for anything specific.

Ask the shop before printing on adhesive:
1. **Bleed:** some vinyl printers ask for 5 mm instead of 3 mm. If so, tell me and I'll generate a 5 mm version.
2. **Cut line:** a rectangular poster is cut with a guillotine, no file needed. A contour cut (custom shape) needs a vector cut line: ask for their format.
3. **White:** on transparent vinyl, the cream background will NOT be printed unless the shop prints a white layer. Use **white** adhesive (paper or vinyl).
4. **Removable adhesive** ("repositionnable"): ask for it so customers' wall paint doesn't come off.
