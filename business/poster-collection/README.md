# POSTER COLLECTION

**Collection 01, “Chefs-d’œuvre” (6 posters, public domain):** Mona Lisa · The Starry Night · The Kiss · The Great Wave · Girl with a Pearl Earring · Impression, Sunrise. Each one in A5, A4 and A3 (+ 3 mm bleed versions) = 36 PDFs, all verified at 300 DPI.

| Folder | Contents |
|---|---|
| 01 ORIGINAL IMAGES | Sources and rights (`SOURCES.md`) |
| 02 ENHANCED IMAGES | Artwork at exactly 300 DPI for each size, sRGB |
| 03 / 04 / 05 … PDF | **Files to give the print shop.** Trim size (A5 148×210, A4 210×297, A3 297×420 mm). The `with 3mm bleed` subfolder is only for shops that ask for bleed. |
| 06 ADHESIVE PRINT FILES | What to check before printing on adhesive |
| 07 PREVIEW IMAGES | Screen previews, the collection image for Instagram (`MASTERPIECES-COLLECTION_instagram_2160x2700.png`, 4:5) and the resolution comparison |
| 08 QUALITY CONTROL REPORT | **Analysis and rights of the 30 uploaded images** + checks on every PDF |

Regenerate or add a design: `python3 business/tools/make_art_print.py business/tools/specs/<design>.json` (high-resolution source that you have the right to use).
